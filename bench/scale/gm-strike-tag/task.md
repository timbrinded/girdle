Let the strikethrough extension render a different HTML element, because some sites want `<s>` rather than `<del>`. `extension.NewStrikethroughHTMLRenderer` should accept options, and a new option `extension.WithStrikethroughHTMLTag(tag string)` sets the element name, so `NewStrikethroughHTMLRenderer(WithStrikethroughHTMLTag("s"))` renders `~~gone~~` as `<s>gone</s>`. The default stays `del`, existing callers keep working, and attributes still render. Add tests. `go vet ./...` and `go test ./...` must pass.
