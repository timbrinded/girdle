Keys are handled as strings joined with dots in places, so a quoted key that contains a dot, `"a.b" = 1`, is confused with the dotted key `a.b = 2`. They are different keys. Make sure quoted keys with dots, and the empty key `""`, work everywhere: decoding, encoding, `MetaData.Type` and `MetaData.Keys`. `Key.String()` must quote a key part when it needs quoting, so the keys above print as `"a.b"`, `a.b` and `""`. `go test ./...` must pass.
