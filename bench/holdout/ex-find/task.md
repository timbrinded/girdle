Add two builtins, `find` and `findIndex`. Both take an array and a predicate, written like the predicates of `filter`, `all` and `any`: `find(ArrayOfFoo, .Value == "baz")` returns the first element for which the predicate is true, and `findIndex(ArrayOfFoo, .Value == "baz")` returns that element's index. The type checker must reject a predicate that doesn't return a boolean, as it does for the other predicate builtins, with an error such as `closure should return boolean (got string)`. They must work in compiled programs, unoptimised programs and `Eval`. `go test ./...` must pass.
