Add variables to the expression language: `let x = 1; x + 2` evaluates to 3. A `let` declaration binds a name to a value for the expression after the `;`. Declarations can follow one another, and they work inside closures, where each iteration gets its own value: `map(1..3, let x = #; let y = x * x; y * y)`, and `map(1..2, let x = #; map(2..3, let y = #; x + y))`. The lexer emits `let`, `=` and `;` as `Operator` tokens. The parser produces a new `ast.VariableDeclaratorNode` with fields `Name string`, `Value Node` (the bound value) and `Expr Node` (the expression that uses it). The type checker, compiler and VM must support it. `go test ./...` must pass.
