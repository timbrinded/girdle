Add the equivalents of the standard library's `flag.Func` and `flag.BoolFunc`. On `*FlagSet`: `Func(name, usage string, fn func(string) error)`, `FuncP(name, shorthand, usage string, fn func(string) error)`, `BoolFunc(name, usage string, fn func(string) error)` and `BoolFuncP(name, shorthand, usage string, fn func(string) error)`. `fn` is called with each value given. A `BoolFunc` flag takes no value, like a bool flag, and can be given as `--name` or `-n`. The type of both is `func`. `go test ./...` must pass.
