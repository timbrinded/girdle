With the HTML renderer's `html.WithLineBreakStrategy(html.SimpleEastAsianLineBreakStrategy)`, a soft line break between two East Asian wide characters is dropped, as it should be. It isn't dropped when either side of the break is inside another inline node, such as emphasis, a link or a code span, or is written as an escape: for `太郎は\ **「こんにちわ」**\ と言った\n**ん**です` the break before `**ん**` is kept. Decide on the characters that are actually displayed on each side of the break, whatever node they're in. `go test ./...` must pass (its `Performance` tests may be skipped).
