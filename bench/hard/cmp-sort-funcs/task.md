`cmpopts.SortSlices` and `cmpopts.SortMaps` only accept a less function, `func(T, T) bool`. Let them also take a compare function, `func(T, T) int`, as `slices.SortFunc` and `cmp.Compare` use, so `SortSlices(func(x, y int) int { ... })` and `SortMaps(time.Time.Compare)` work. Anything else must still panic with a message containing `invalid less or compare function`. `go test ./...` must pass.
