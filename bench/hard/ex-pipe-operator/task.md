Add a pipe operator to the expression language. `a | f(b, c)` means `f(a, b, c)`: the value on the left becomes the first argument of the call on the right. Pipes chain from left to right and work with builtins that take a predicate, so `1..9 | map(# + 1) | filter(# % 2 == 0)` is `filter(map(1..9, # + 1), # % 2 == 0)`, and `"%s bar %d" | sprintf("foo", -42 | abs())` is `sprintf("%s bar %d", "foo", abs(-42))`. The parser must produce the same AST as the equivalent nested calls. `go test ./...` must pass.
