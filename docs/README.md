# Documentation

Start with [getting started](getting-started.md), then [usage](usage.md). The [configuration reference](configuration.md) describes the options for an installed binary; `girdle -h` shows the flags in the version you built.

| Topic | Read this |
| --- | --- |
| Install and run | [Getting started](getting-started.md) |
| Use the terminal UI or automate a request | [Usage](usage.md) |
| Choose providers, models and features | [Configuration](configuration.md) |
| Understand ownership and request execution | [Architecture](architecture.md) |
| Understand access and data handling | [Security](../SECURITY.md) |
| Measure a change | [Benchmarks](benchmarks.md) |
| Develop a change | [Contributing](../CONTRIBUTING.md) |
| Understand earlier choices | [Decisions](decisions/README.md) and [research](../research/README.md) |

The guides describe the current implementation. Decisions and research notes are dated records: later records may replace a default, remove a feature or revise a measurement method. Their original results are retained.

The [SVG assets](assets/README.md) include the banner, logo and architecture diagram used by these docs.
